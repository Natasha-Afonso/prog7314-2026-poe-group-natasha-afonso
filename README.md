# MeTrix Android Application
Our app entails of a personal companion where users can express themselves by customizing their avatar and engaging in self-care activities. Self-care activities include journaling, hydration tracker, wardrobe (outfit) management, fitness tracker, and tracking habits through a virtual avatar. The gamification aspect is accomplished through dressing up the avatar linked to the outfit management feature. The user can upload their clothing items and they get saved into the wardrobe.  
<br>

## Architecture Choices ⚒️
- Frontend- Kotlin using Jetpack Compose
- Backend - C# ASP.NET Web API Core
- Database - SQL Server
- Dockerized the backend and database
- Authentication- Firebase
- Saving Images - Azure Blob Storage
<br>

## MeTrix Features 🚀

### User Authentication 🔐
- Users can sign up and sign in by entering their email address and password which are handled by Firebase
- Users can also choose to Google SSO option
<br>

### On-Boarding 🎬
- During the onboarding experience the user enters their birthday, nickname, personality and aspiration.
<br>

### Settings ⚙️
- The user can customize their application experience by changing the theme, text size and colour contrast.
<br>

### Journal 📔
- User can create, update, read and delete their journal entries
- When creating an entry the user can choose how they feel by clicking an emoji.
- User is asked reflectional journal prompts when opening their digital journal book
<br>

### Wardrobe 👕👖👗👚
- The user can customize their wardrobe background
- Users can upload image of their clothes to add it to their wardrobe collection
- Users can add certain clothes they have an image of in a wishlist
<br>

### Shop 🏪🪙
- User can purchase items using their earned gold coins
- User can see what they have purchased from their cart
<br>

### Magazine 📖
- The user receives a weekly magazine fixture that summarizes their in-app activities
<br>

### Habits and Goals 🎯🪙
- Users can create habits/goals and categories
- All accomplished goals will allow them to earn gold coins
<br>

### Self Care Activities 👟🫗
- User can link Metrix to Samsung Health Connect so that their steps can be recorded
- User sees their self care activities progress in the home
- Activities like water intake, cardio(step count) and hygiene (brushing their teeth)
<br>

### In-App Calendar 📅
- User can create an outfit and optionally schedule the outfit to wear on that specific day.  
- Calendar is going to save the users birthday and national holidays.
<br>

### Profile Customization ©️
- User can customize their avatar (mini me)
- Customizable features include changing the avatars eye color, hair style, hair color, skin colour and lip shade.
<br>
